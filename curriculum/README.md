# Ετήσιος κατάλογος ύλης

Το catalog-2026-2027.json είναι το ελεγχόμενο στιγμιότυπο ύλης για το σχολικό έτος 2026–2027. Εισάγεται στη βάση με python -m database init. Το app.py διαβάζει από τη βάση, με διατήρηση των παλιών URLs. Τα JSON παραμένουν το ελεγχόμενο στιγμιότυπο της αρχικής εισαγωγής.

- sources.json: επίσημα URLs, μέλη ZIP, ημερομηνία ελέγχου και SHA-256. Το source-cache/ κρατά τα ακριβή αρχεία που διαβάστηκαν.
- expected-references.json: απογραφή παραγράφων για έλεγχο ελλείψεων ανά μάθημα.
- ../docs/CURRICULUM_STAGE_2.md: ανθρώπινα αναγνώσιμη αναφορά.

Επίπεδα: σχολείο → τάξη/διαδρομή μαθήματος → κεφάλαιο → ενότητα → στόχοι. Τα prerequisite_skills αποτελούν χωριστό άκυκλο δίκτυο δεξιοτήτων, με ρητή δήλωση παιδαγωγικής προέλευσης.

Μια εγγραφή ενότητας δεν σημαίνει έτοιμο μάθημα ή κουίζ. Το coverage διακρίνει missing από existing_unreviewed. Κανένα υπάρχον περιεχόμενο δεν έχει χαρακτηριστεί εκπαιδευτικά πιστοποιημένο.

Η σειρά display_order μπορεί να αλλάζει χωρίς αλλαγή UUID. Διατηρήστε τα αναγνωριστικά σε διορθώσεις τίτλων. Νέο βιβλίο ή διαφορετικός διαχωρισμός ενότητας χρειάζεται ρητή απόφαση αντιστοίχισης.

Έλεγχος από τη ρίζα project:

```powershell
.\.venv\Scripts\python.exe -B scripts\validate_curriculum.py
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```
