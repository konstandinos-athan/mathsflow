# Επικοινωνία χωρίς email — τοπική υλοποίηση

Η επικοινωνία απαιτεί συνδεδεμένο λογαριασμό. /account/contact: νέα αιτήματα, έως3/ώρα ανά λογαριασμό και ευρύτερο IP throttle, CSRF, όριο3000 χαρακτήρων, ιδιωτικές απαντήσεις. /account/admin/contact: μόνο admin, CSRF και περιορισμός απαντήσεων. HTML escaping σε μηνύματα και απαντήσεις. Τα αιτήματα περιλαμβάνονται στο export και διαγράφονται με τον λογαριασμό μέσω FK cascade.

Αφορά χρήστες με πρόσβαση στον λογαριασμό τους. Δεν υποκαθιστά δημόσιο κανάλι για ανώνυμους επισκέπτες, απώλεια πρόσβασης ή όλα τα νόμιμα στοιχεία επικοινωνίας. Δεν αρκεί από μόνη της για ενεργοποίηση δημόσιων εγγραφών. Απαιτεί πραγματικό διαχειριστή και τακτικό έλεγχο εισερχομένων· δεν αποστέλλει ειδοποιήσεις email.

Νέες migrations: SQLite006_contact.sql, PostgreSQL002_contact.sql. Δεν εφαρμόστηκαν σε production. Ο admin πρέπει να οριστεί από τον ιδιοκτήτη σε επαληθευμένο δικό του λογαριασμό, χωρίς κοινόχρηστους κωδικούς ή αυτόματη αναβάθμιση πρώτου χρήστη. Η μετάβαση Neon βρίσκεται ακόμη σε εξέλιξη, παρότι οι8 αρχικοί PostgreSQL integration checks πέρασαν.
